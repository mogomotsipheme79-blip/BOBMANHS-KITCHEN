# BOBMANH'S KITCHEN - Website

Student: BOBMANH'S KITCHEN Website
Module: Responsive Web Design

## Project Overview
A 5-page responsive restaurant website: Home, Menu, About, Gallery, Contact.

## Design Features Implemented
1.  **Advanced Layout (2.4):** Home hero uses CSS Grid with `grid-template-areas: "image text"` for desktop and stacks to single column on mobile.
2.  **Visual Polish (2.5):** Cards use `box-shadow`, `border-radius`, and `transform: translateY(-5px)` on hover for interaction.
3.  **Responsive Design (2.6):** Media query @768px changes nav to column, hero to 1 column, gallery to 1 column, cards to full-width.
4.  **Typography:** Poppins font imported from Google Fonts.
5.  **Accessibility:** Semantic HTML, alt text for all images, label associations in contact form.

## Technologies
- HTML5
- CSS3 (Flexbox + Grid)
- No frameworks

## How to View
Open index.html in browser or via Live Server in VS Code.

## Responsive Breakpoints
- Desktop: >768px (3-column gallery, 2-column hero)
- Mobile: ≤768px (single column)
